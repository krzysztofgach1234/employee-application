# Test Plan – Employee Application

## 1. Introduction
The purpose of this test plan is to verify the core functionality of the employee application, with a focus on login, absence management, and payroll documents.

---

## 2. Test Scope

### Functional Testing
- User login and logout
- “Absences” module (leave requests)
- Payroll documents

### Negative Testing
- Form validation
- Invalid input handling
- Limit boundary checks

### Non-functional Testing
- Password masking
- User session management
- Login data persistence

---

## 3. Test Environment
- Device: Realme 9
- OS: Android 14
- Application: Employee application

---

## 4. Testing Approach
Testing will be performed based on prepared test cases covering positive, negative, and non-functional scenarios.

---

## 5. Success Criteria
- No critical bugs blocking application usage
- Core functionalities work as expected
- No application crashes during execution
