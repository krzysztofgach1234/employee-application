# QA Portfolio

This repository contains sample QA documentation for an employee mobile application.  
It demonstrates skills in test planning, test case design, test execution, and bug reporting.

---

## Project Scope

The testing covers the following modules:

- Login functionality
- Absence management
- Payroll documents

---

## Repository Structure

```
QA-Portfolio/
│
├── README.md
├── test-plan.md
├── test-execution.md
│
├── test-cases/
│   ├── login.md
│   ├── absences.md
│   ├── payroll-documents.md
│
├── bug-reports/
│   ├── login-bugs.md
│   ├── absences-bugs.md
│   ├── payroll-document-bugs.md
```

---

## Test Cases

Test cases define expected behavior of the system and are grouped by module.

Covered areas:
- Login functionality
- Date filtering
- Navigation and state handling

---

## Test Execution

The `test-execution.md` file contains the results of executed test cases, including:

- Pass/Fail status
- Execution summary per module
- Identified defects during testing
- Overall testing conclusion

This demonstrates the ability to not only design tests, but also execute and analyze results.

---

## Bug Reports

Bug reports document issues found during testing. Each report includes:

- Title
- Description
- Environment
- Steps to reproduce
- Expected vs Actual result
- Impact level

---

## Purpose of this repository

The goal of this project is to demonstrate:

- QA documentation skills
- ability to design structured test cases
- understanding of test execution process
- ability to identify and report defects clearly
- analytical thinking in software testing
